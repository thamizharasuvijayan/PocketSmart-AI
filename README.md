
# PocketSmart AI — Smart Budget & Recommendation Assistant

## College Project
A simple personal finance web application built with Python Flask, SQLite, HTML, CSS and JavaScript.

### Main modules
1. User registration/login
2. Income and expense management
3. Category-based expense tracking
4. Monthly budget setting
5. Dashboard with financial summary
6. Expense category chart
7. Rule-based smart recommendations
8. Transaction deletion

## How to run
1. Install Python 3.10+.
2. Open this project folder in Terminal/Command Prompt.
3. Run:
   `pip install -r requirements.txt`
4. Start:
   `python app.py`
5. Open:
   `http://127.0.0.1:5000`

The SQLite database `pocketsmart.db` is automatically created on first run.

## Demo flow
Register → Add income → Set monthly budget → Add expenses → View dashboard → Explain chart and smart recommendations.

## Note
The "AI" component in this college version is an explainable recommendation engine based on spending rules. It does not require an external AI API, so the project can be demonstrated offline.
